# 🚚 Jasa Angkut Jakarta - Web Platform

Platform web responsif yang dirancang untuk mendigitalisasi layanan operasional UMKM jasa angkut tanah, pasir, dan puing di wilayah Jakarta. Proyek ini bertujuan untuk mempermudah calon pelanggan dalam melihat rincian armada, estimasi layanan, serta melakukan pemesanan secara langsung.

## 🚀 Fitur Utama
* **Responsive Landing Page:** Tampilan optimal diakses lewat smartphone maupun desktop.
* **Kalkulator / Info Armada:** Menampilkan detail kapasitas truk dan jenis angkutan.
* **Direct Contact Integration:** Tombol interaktif langsung terhubung ke layanan komunikasi.

## 🛠️ Tech Stack
* **HTML5** & **CSS3** (Custom Styling & Flexbox/Grid)
* **JavaScript (ES6+)** (Interactive UI & DOM Manipulation)
* **Git & GitHub Pages** (Version Control & Hosting Deployment)
